# OpenRoot Bounty Board (v1.0)

Currencies: credits (paid) and PoPW reputation (measured joules or mass/photo hang, sealed).

Lifecycle: MINT -> CLAIM -> VERIFY (builder node + >= 1 independent auditor reproduce)
-> SEAL (SHA256 receipt into pathway cache) -> PAY (only after seal).

Acceptance criteria must be MEASURABLE DELTAS. Examples seeded below.

| id | bounty | measurable acceptance |
|---|--------|----------------------|
| BB-001 | Perfect aerodisc panel 3D printer, open code | prints panel; alpha >= 0.95 verified by calorimeter delta |
| BB-002 | Aerocement delta-T jet motor printer code | sustained delta-T >= 3.7 K on flat spiral pan build guide |
| BB-003 | Waste-to-3D-printer (passive vehicle feedstock) | filament from feedstock; print completion; photo-hang of both |
| BB-004 | Stirling flywheel-belt system | clutch + deadman interlock demonstrated; energy metered in/out |
| BB-005 | Belt-driven home appliance | runs from BB-004 belt; power draw metered; no grid connection |
| BB-006 | Cloud-9 aerostat community hub | tethered lift + descent logged; payload mass measured |
| BB-007 | Interplanetary vehicle variant + hub mega-printer | delta of previous sealed bounties composed; hard-vacuum sim delta recorded |

Rules:
- Hardware bounty = recipe + measurement, not a shipped object (N09 mass-or-photo).
- Fabricated evidence costs standing permanently. Cheating must be more expensive than building.
- Reduced-rate ATTESTED payouts for single-source results; full credit only for reproduced.
