# Security Policy

## Local-first boundary

OpenRoot does not commit personal documents, live SQLite databases, embeddings,
model files, archives, logs, API keys, tokens, SSH material, phone exports, or
machine-specific runtime state.

## Reporting

Do not create a public issue for a suspected credential exposure, private-data
exposure, or destructive workflow defect. Report privately via GitHub security
advisories and include:

- affected path or component
- minimal reproduction steps
- redacted evidence
- suggested mitigation, if known

## Promotion policy

Automation may inspect, propose, test, and generate evidence. A human operator
reviews and promotes changes to GitHub.
