# How to begin the first real oscillation

When you are ready to execute Cycle-001:

1. Choose one public open-source repository (satellite / ground station / mesh / offline tool).
2. Fork it on GitHub.
3. Come back here and fill oscillation/cycles/cycle-001/notes.md with the URLs.
4. Then run the next pure block that will be given for the actual local clone + module extraction.

The infrastructure is now ready.
The only missing piece is the first concrete target repository.
