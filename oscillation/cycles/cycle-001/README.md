# Cycle-001 — First Live Oscillation

Status: prepared, not yet executed

## Purpose
Execute the first full bidirectional loop:
Fork → examine modules → ask the two questions → contribute / reassemble → push back → record α_A movement.

## Chosen starting domain
Open satellite / ground-station / low-tech signal reception space
(matches the chicken-wire receiver + Cloud Nine direction)

## Exact steps when ready
1. Pick one public repository in the target domain.
2. Fork it to your GitHub account.
3. Clone the fork locally beside openroot.
4. Strip both projects into the smallest clean modules that matter.
5. Write the answers to:
   - How can OpenRoot improve this project?
   - How can this project improve OpenRoot?
6. Make the smallest useful improvement on their side and on our side.
7. Push both directions.
8. Record the measured gain (even qualitative) into the seed and into this cycle folder.
