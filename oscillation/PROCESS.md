# Oscillation Process (Adoption Engine)

1. Identify an open-source project that already does something useful (satellite tools, mesh networking, low-tech construction, offline knowledge systems, etc.).
2. Fork it.
3. Ask the two questions in both directions:
   - How can OpenRoot build / improve this project?
   - How can this project build / improve OpenRoot?
4. Strip both sides into the smallest clean modules.
5. Reassemble the strongest combination.
6. Push the improvements back to the original project and into OpenRoot.
7. Record the cycle in the seed (what was gained, what α_A moved).

This loop is the primary public expansion mechanism.
It does not require permission, capital, or land.
It only requires clear modules and measured improvement.
