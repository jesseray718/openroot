## At the Location

### ✅ Initial Setup
1. Connect monitor, keyboard, mouse
2. Plug in power cable
3. Press power button
4. Observe LED behavior
5. Note any error codes

### ✅ If It Turns On Then Off
1. Unplug power
2. Hold power button 30 seconds
3. Open case, check connections
4. Try with minimal hardware (1 RAM stick)
5. Check CMOS battery

### ✅ BIOS Access
1. Power on
2. Immediately press F2 repeatedly
3. If no response, try F12
4. If still no response, proceed to CMOS reset

### ✅ CMOS Reset
1. Unplug power
2. Open case
3. Remove CMOS battery (CR2032)
4. Wait 5 minutes
5. Reinsert battery
6. Reconnect power
7. Try booting

### ✅ Ubuntu Installation
1. Insert flash drive with Ubuntu ISO
2. Boot, press F12 for boot menu
3. Select USB drive
4. Choose "Try or Install Ubuntu"
5. Follow prompts (erase disk for clean install)
6. Complete setup

### ✅ Bluetooth Setup
1. Update system (sudo apt update && sudo apt upgrade)
2. Install Bluetooth tools (sudo apt install bluetooth bluez blueman)
3. Start service (sudo systemctl start bluetooth)
4. Add user to bluetooth group
5. Reboot
6. Pair devices via bluetoothctl
