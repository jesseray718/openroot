# Decentralized Mirror Plan
To ensure this technology cannot be censored:

1. **GitHub:** Primary repo (https://github.com/...)
2. **Zenodo:** Immutable DOI (https://zenodo.org/...)
3. **IPFS:** 
   - Install IPFS: `pkg install ipfs`
   - Add file: `ipfs add -r rns/`
   - Pin the hash to a public node.
4. **Archive.org:** Submit the repo URL to the Wayback Machine.
5. **Torrent:** Generate a torrent file for offline sharing.

*"The truth cannot be deleted if it is everywhere."*
