# Security Policy

## ⚠️ Safety Warning
The Renaissance Protocol involves **High-Temperature Thermodynamics** and **HHO (Hydrogen-Oxygen) Gas**.
- **HHO is Explosive:** Improper handling can cause severe injury or death.
- **High Heat:** Components can cause burns.
- **Pressure:** Systems operate under pressure.

## 🛡️ Reporting a Vulnerability
If you find a design flaw that could cause an explosion, fire, or structural failure:
1. **DO NOT** post it publicly in the Issues tab immediately.
2. **Email** the maintainer directly (if contact info is provided) or use GitHub's "Private Security Advisory" feature.
3. Include:
   - Description of the flaw.
   - Potential consequences.
   - Suggested fix.

This technology is provided **"AS IS"**.
- The authors are **not liable** for any injuries, deaths, or damages resulting from the use of this technology.
- You build this system **at your own risk**.
- Always consult with a qualified engineer before building.
- Always follow local building codes and safety regulations.

## ✅ Safe Practices
- Always use **Flashback Arrestors** on HHO lines.
- Never store HHO gas in tanks.
- Ensure proper ventilation.
- Wear protective gear (gloves, goggles).
- Test small prototypes before scaling.
