## Contribution Guide

### How to Add Knowledge
1. Fork the repository
2. Add your knowledge in the appropriate section
3. Follow the existing format
4. Include both primitive and modern aspects
5. Submit pull request

### Knowledge Standards
- **Verifiable**: Must be testable
- **Practical**: Immediately actionable
- **Complete**: Cover primitive and modern
- **Clear**: Easy to understand
- **Illustrated**: Include diagrams when possible
