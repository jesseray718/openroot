# Mistake 5991272f4502dc56

SHA256-shape key: 5991272f4502dc56

## Solution
gh PRs need the head branch pushed to origin first — "No commits between main and X" + "Head ref must be a branch" = branch-not-on-remote, not empty-diff. Gate every gh pr create behind: git show-ref refs/remotes/origin/<br>. Also: never 2>/dev/null a fallible gh call — stderr is the diagnosis.
