# Mistake 7ca79d4cf6c0f823

SHA256-shape key: 7ca79d4cf6c0f823

## Solution
authorized_keys2 does not exist on optiplex; the [ -f "$f" ] && ssh-keygen guard short-circuits to exit 1 and the ERR-hook composted the read-only fingerprint probe (x2 while last-status stayed 1). Harmless probe; prevent with: for f in ~/.ssh/authorized_keys*; do [ -f "$f" ] && ssh-keygen -lf "$f"; done; true
