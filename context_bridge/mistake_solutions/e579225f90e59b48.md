# Mistake e579225f90e59b48

SHA256-shape key: e579225f90e59b48

## Solution
Pasting multi-line scripts into an interactive bash prompt corrupts them: history expansion fires on exclamation-mark characters (shebangs), and sudo password prompts eat leading lines, leaving dangling heredocs. Fix: run set +H first, then land the whole script on disk via one outer heredoc and execute with bash file.sh. If terminal output shows script lines echoed back with no continuation prompts, the paste failed and the file is corrupt.
