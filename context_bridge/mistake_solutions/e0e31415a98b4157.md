# Mistake e0e31415a98b4157

SHA256-shape key: e0e31415a98b4157

## Solution
tail path bug: 'ls -t dir/pattern' already emits full paths; piping to basename then re-prefixing the dir doubles the filename (rapl_sampler_rapl_sampler_*). Pattern fix: LOG=$(ls -t logs/rapl_sampler_*.log | head -1); tail -5 "$LOG" — no basename round-trip. Class: PATH-DOUBLE-PREFIX, do not requeue.
