Pod Loader Tool
Convert any text into a sealed SQLite3 pod with dual-hash content addressing, FTS5 indexing, and optional nomic embeddings. 
git clone https://github.com/jesseray718/openroot
cd openroot
python3 bin/pod_loader_v1.py ingest my_pod ./my_docs/
python3 bin/pod_loader_v1.py seal my_pod
python3 bin/pod_loader_v1.py query my_pod "your query"
