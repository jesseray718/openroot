# AE-GFRC Physical Test Plan
**UNE:** DV.GEN.TH.AE01.PTP
**Version:** 1.0
**Date:** 2026-07-09

## Test Objective
Validate the corrected AE-GFRC mix protocol through physical testing and document all findings for protocol refinement.

## Test Parameters

### Materials
- Cement: Type I/II Portland
- Glass fiber: Alkali-resistant, ≥16% ZrO₂
- Xanthan gum: Food grade
- Activated carbon: Powder, fine
- Foaming agent: Protein-based
- Water: Clean, potable

### Equipment
- Mixing vessel (5gal bucket)
- Drill paddle mixer
- Scale (0.1g resolution)
- Mold (12"x12"x2")
- Release agent (vegetable oil)
- Thermometer (probe type)
- Infrared thermometer
- Camera/phone for documentation
- Timer

## Test Procedure

### Preparation
1. Gather all materials and equipment
2. Set up work area with proper ventilation
3. Put on appropriate PPE
4. Calibrate scale and measuring equipment

### Mixing
1. Follow corrected mix protocol exactly
2. Document each step with photos
3. Record mixing times and conditions
4. Note any deviations from protocol

### Pouring
1. Prepare mold with release agent
2. Pour mixture in single continuous pour
3. Tap mold gently to release air bubbles
4. Level surface and cover

### Curing
1. Follow 21-day cure schedule
2. Document daily temperature and humidity
3. Perform checkpoints as scheduled
4. Take photos at each checkpoint

## Data Collection

### Mix Documentation
- Exact material weights and ratios
- Mixing times and speeds
- Environmental conditions
- Any observations or issues

### Cure Documentation
- Daily temperature and humidity logs
- Photos at each checkpoint
- Any anomalies or unexpected events

### Test Results
- Density measurements
- Water absorption test results
- Thermal performance data
- Visual inspection findings

## Analysis Plan

### Density Verification
- Calculate density from weight/volume measurements
- Compare with target (< 1200 kg/m³)
- Document any discrepancies

### Open-Cell Verification
- Perform water absorption test
- Document absorption rate and pattern
- Compare with control samples

### Thermal Performance
- Conduct surface temperature measurements
- Compare with standard concrete control
- Document temperature differentials

## Reporting

### Test Report Structure
1. Executive Summary
2. Test Objectives
3. Materials and Methods
4. Results
5. Analysis
6. Conclusions
7. Recommendations

### Documentation Format
- Markdown file in research/thermal-systems/
- Comprehensive photo gallery
- Data tables and charts
- Detailed observations

## Timeline
- Day 1: Mixing and pouring
- Days 2-21: Curing and documentation
- Day 22: Final testing and analysis
- Day 23: Report completion

## Success Criteria
- Successful mix with stable foam
- Proper curing with minimal cracking
- Density within target range
- Positive thermal performance indicators
- Comprehensive documentation

## Contingency Plan
- If foam collapses: adjust xanthan gum and retry
- If thermal performance poor: adjust activated carbon and retry
- If structural issues: adjust fiber content and retry
- Document all iterations and findings
