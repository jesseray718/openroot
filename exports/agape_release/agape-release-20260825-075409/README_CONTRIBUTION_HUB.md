# OpenRoot Contribution Hub

This directory is a planning, provenance, and contribution-routing workspace.

It exists to separate useful, reviewable pieces of OpenRoot work into small,
honest, maintainable contributions for the projects and communities that may
benefit from them.

This is not a claim that every OpenRoot idea is validated, production-ready,
or appropriate for every upstream project.

## Core principles

- Serve the lowest-resource participant first.
- Preserve authorship, provenance, licensing, and uncertainty.
- Prefer small, independently useful changes over large manifestos.
- Keep concepts, simulations, sourced claims, and field measurements distinct.
- Ask maintainers before submitting work where project scope is uncertain.
- Do not make safety, power, RF, structural, financial, or performance claims
  without appropriate evidence and review.
