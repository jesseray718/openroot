# ACRE Token — Proof of Innovation

> **Status: Not yet launched.** ACRE tokens do not currently exist.
> Launch requires: 3 verified nodes in different climates + legal opinion
> on utility token classification. No financial promises are made here.
> This document describes the intended design only.

## What ACRE Will Be

A utility token minted only when the commons materially improves — new knowledge,
a debugged flaw, a node validated in a new context. Not for hours logged, effort,
or repetition. No pre-mine. No speculation.

## What Will Earn ACRE

Full category definitions and payout ranges: [ACRE_SPECIFICATION.md](ACRE_SPECIFICATION.md)

| Category | Example | Range |
|----------|---------|-------|
| First node in a new climate zone | Node Zero, first AZ node | 15,000–20,000 |
| Hardware bug fix / optimization | Desiccant placement fix | 5,000–50,000 |
| New tool or script | Sensor logger rewrite | 5,000–50,000 |
| Software bug fix | Calibration formula fix | 1,000–20,000 |
| New skill document | Aerocement mixing guide | 5,000–20,000 |
| Bounty won | Per bounty | 1,000–150,000 |
| Validator inspection | Any inspection, incl. replicas | 100 |

Replicating a known build in an already-validated climate/context earns **0** —
real work, but not new knowledge to the commons.

## What ACRE Will Buy
- Land time-shares on OpenRoot demonstration sites
- Resource credits (cold hours, energy, processing time)
- Governance votes on project direction

## Governance Design
Quadratic voting. No entity holds more than 2% voting power.
Founder holds no special keys. No veto. Community supreme.
