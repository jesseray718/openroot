# OpenRoot Seed Core

**The absorption & seed library at the center of inter-session context**

This repository is the living center of how knowledge, intention, and optimized query patterns are absorbed into the OpenRoot / UNE context bridge. It turns ephemeral conversation into durable, verifiable, η-weighted seeds that future sessions (human or AI) can load with near-zero loss.

## What a Seed Is

A seed is a compact, structured, high-signal packet of intent, optimized query patterns, domain framing, thermodynamic / η constraints, and cross-links to the larger OpenRoot ledger.

Seeds are written once, absorbed into `/sdcard/openroot/session_seeds/`, and become part of the permanent inter-session memory fabric.

## Core Design Principles

1. η first — every seed must increase useful joules relative to the human joules required to use it.
2. Verifiable — where possible, seeds reference the thermodynamic ledger and cryptographic hashing of meaning.
3. Atomic + composable — small seeds chain into larger capability.
4. Absolute path discipline — no tilde, no ambiguity.
5. Structure-enforceable — seeds must survive the UNE structure enforcer.
