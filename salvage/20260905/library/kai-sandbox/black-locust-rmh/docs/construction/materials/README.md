## How These Fit the System

- Domes are **nodes**, not houses. Each BOM supports the physical layer of fractal mesh + H-003 thermal cascade + 50-person mutual-aid crews.
- Material choice aligns with stored dome construction method: triangular panels with folded edges → voids pumped with GFRC (Zr + activated carbon) — eliminates separate flange materials and cuts labor ~18%.
- Pneumatic hog-ring tooling is the labor-multiplicity lever for mesh/ferrocement assembly at crew scale.
- Prices are 2026 industrial averages; always re-quote local before procurement.
