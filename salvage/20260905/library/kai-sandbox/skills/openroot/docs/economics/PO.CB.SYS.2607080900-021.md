# PO-021 — The Rent Backfill Spike

**Domain:** Credit & Business (CB)
**Type:** Postulate
**Status:** Active

## Statement

On a credit file with fewer than three tradelines, the addition of 24 months of backfilled rent payment history produces a disproportionate score increase relative to the same history added to a thick file. The thinner the file, the higher the marginal yield per backfilled month.

## Derivation

By AX-CB-005 (Thin File Volatility), each data point on a thin file has outsized impact. Rent reporting adds a new tradeline with 24 months of history. On a file with 1 existing account, this doubles the account count and may triple the apparent age. On a file with 10 accounts, the same addition is marginal. The yield curve is inversely proportional to file thickness.

## Cross-References

- AX-CB-005 (Thin File Volatility Principle)
- AX-CB-008 (Backfill Yield)

## Application

Submit rent backfill immediately on any file with fewer than 3 tradelines. The thinner the file, the more urgent the backfill. Cost: $50 one-time. Expected yield: 15-40+ points depending on file thickness and existing account age.
