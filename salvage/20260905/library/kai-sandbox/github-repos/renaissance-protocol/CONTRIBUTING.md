# Contributing to the Renaissance Protocol

Thank you for wanting to help build the future of energy. This project is **Open Source** and **Anti-Monopoly**. We welcome contributions from builders, engineers, and scientists worldwide.

## 🛡️ Our Philosophy
- **Open Source:** All code and designs must remain free.
- **No Patents:** You cannot patent improvements to the core technology.
- **Safety First:** This involves high-pressure gas (HHO) and heat. Safety is paramount.
- **Community Owned:** We are building a commons, not a product.

## 🚀 How to Contribute

### 1. Reporting Bugs
Found a flaw in the physics or a typo in the build guide?
- Open an **Issue** on GitHub.
- Label it `bug`.
- Include: System configuration, error message, and steps to reproduce.

### 2. Suggesting Improvements
Have a better way to mix the cement or optimize the spiral?
- Open an **Issue** labeled `enhancement`.
- Provide data or calculations to support your claim.
- **Note:** All improvements must be licensed under the **Renaissance Protocol License (RPL)**.

### 3. Submitting Code or Designs
- Fork the repository.
- Create a branch: `git checkout -b feature/my-improvement`.
- Make your changes.
- **Update Documentation:** If you change the physics, update the `docs/physics/` files.
- **Submit a Pull Request (PR):**
  - Describe what you changed.
  - Explain *why* it improves the system.
  - Confirm you agree to license your contribution under the RPL.

### 4. Building & Testing
- **Build your own prototype.**
- Share your **build logs** (photos, temperature readings, costs).
- Post your results in the **Discussions** tab.
- **Safety Warning:** When testing HHO, always use flashback arrestors and work in a ventilated area. The maintainers are not liable for accidents.

## 📜 License Agreement
By contributing to this project, you agree that your contributions will be licensed under the **Renaissance Protocol License (RPL)**. This ensures your work remains free for humanity forever.

## 🤝 Code of Conduct
- **Respect:** We are building a better world. Treat everyone with dignity.
- **Evidence:** Claims must be backed by data or physics.
- **No Gatekeeping:** We welcome beginners. Explain things clearly.
- **Anti-Monopoly:** Do not attempt to restrict access to this technology.

## 📞 Contact
- **Discussions:** Use the GitHub Discussions tab.
- **Issues:** Use the GitHub Issues tab.
- **Emergency Safety:** If a design poses an immediate danger, contact the maintainer directly.
