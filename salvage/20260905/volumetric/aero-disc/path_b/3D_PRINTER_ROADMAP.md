# Open-Source 3D Printer Roadmap for Path B Material

## Vision
A family of simple, low-cost, open-source printers optimized for the thixotropic closed/open-cell cementitious feedstock.

## Phases

Phase 0 — Material characterization (current)
Phase 1 — Minimal viable extruder matched to gel rheology
Phase 2 — Cartesian or CoreXY frame sized for one Aero-Disc or modular tiles
Phase 3 — Process control (pressure monitoring, optional secondary shear)
Phase 4 — Component library (parametric Aero-Disc, manifolds, tank panels, vehicle cones)
Phase 5 — Self-replication and global accessibility documentation

## Limitations
Cementitious printing is slower and more process-sensitive than thermoplastic FDM. Surface finish and dimensional accuracy will initially be lower. Structural certification for load-bearing or vehicle use requires independent testing far beyond the first releases.

All mechanical designs, firmware, and process documentation released under the same dual license as the parent project.
