# Contributing to OpenRoot Aero-Disc

Thank you for considering a contribution. This project is optimized for high-signal technical collaboration.

## Preferred contribution path

1. Open an Issue using one of the provided templates before writing large amounts of code or text.
2. Prefer quantitative claims, references, and proposed experiments.
3. Soft ideas and brainstorming belong in GitHub Discussions.
4. Measured data (ΔP, temperatures, pore-size distributions, strength) is the highest-value contribution.

## Code and documentation style

- Python scripts must remain stdlib-only unless a clear, justified dependency is agreed in an Issue.
- Dimensions and performance claims must carry units and uncertainty or bounds.
- η language is preferred: useful joules / human joules.
