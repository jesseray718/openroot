# OpenRoot Aero-Disc Roadmap

## Guiding Principle
η = useful joules delivered / human joules expended.

## Near-term (0–3 months)
- First physical Path A disc built and ΔP / NTU measured
- Greenhouse gap temperatures instrumented
- Python sizing script updated with measured buoyancy
- Path B small-batch gel trials published with raw data
- Issue templates exercised by external engineers/scientists

## Mid-term (3–12 months)
- Path A design iterated to measured optimum
- First dual-structure (closed-skin / open-core) samples demonstrated
- Minimal open-source extruder prototype
- Integration of Aero-Disc into complete OpenRoot thermal cascade
- First public build log from a second independent site

## Longer-term
- Printable Aero-Disc and modular tile library
- Vehicle concept branch (deep φ-spiraling wet cone + ΔT motor)
- Formal coupling to computational_flow ledger and ACRE minting
- Multi-climate validation

## Community Design
The repository is engineered so the lowest-friction high-value action for a new engineer or scientist is to open a well-formed Issue.
