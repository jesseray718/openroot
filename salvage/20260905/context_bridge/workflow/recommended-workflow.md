# Recommended Workflow (OpenRoot Lattice)

1. Absolute paths only. Never use tilde.
2. Prefer idempotent scripts (safe to re-run).
3. For upstream / forked repos: append lattice notes, never overwrite full upstream READMEs.
4. Keep one canonical copy of shared documents; point other repos to it.
5. After any major session, extract a perfect-run script into /sdcard/openroot/tidbits/perfect-runs/.
6. Use openroot-run / openroot-absorb / openroot-inventory as the closed loop.
7. Private archive (jesseray718-archive) is the snapshot of record.
