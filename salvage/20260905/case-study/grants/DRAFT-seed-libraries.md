# Draft: Open Seed Libraries + Workshop Hubs
**Ask focus:** Starter kits, open curriculum, and first wave of community hubs in the SE Missouri bioregion and peer regions.

**Why this funder type:** Food sovereignty, agricultural resilience, and community foundation programs.

**Core claim:** Full planetary network is only 2.5–4% of one year of commercial seed + agrochemical spend; a regional wave is modest and permanent.

**Deliverables:**
- Open kit list + fabrication instructions
- Local seed + tool library operating ledger (already built)
- Training materials that any library or extension office can run
- Public yield report (varieties shared, participants, autonomy metrics)
