# OpenRoot Structure v2 — Two-Point Interlocking Form

## Core Law
Every major piece has exactly two points:
1. Seed  (pure, compressed, high-η essence)
2. Bridge (living multiplier that connects it to the rest of the system)

## Directory Roles
- seeds/ + seed-core/seeds/   → pure Seeds
- bridges/                    → living Bridges
- symbols/                    → canonical statements + cryptographic hashes
- ledger/ + ledger.jsonl      → thermodynamic truth (η record)
- physical/                   → aerocement, black-locust, hearth, etc.
- engine/                     → computational_flow + context_bridge
- wiki/                       → human-readable surface

## Interlocking Rule
- Every Seed must name the Bridges it activates
- Every Bridge must name the Seeds it multiplies
- Only the thermodynamic ledger records whether the pair raised η
