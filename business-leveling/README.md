# OpenRoot Business Leveling Cooperative

Autonomous capital + business-credit pool for LLCs, startups, and small operators.

No owners. No corporate extraction.  
Members invest capital only.  
Pool compounds and returns dividends.  
Fixed percentage of surplus is automatic hand-up.  
Governance power is deliberately separated from capital size.

Hardened against:
- Whale takeover
- Weak-point exploitation
- Brute-force influence
- Capture by any external authority

Zero external dependencies (bash + python3 stdlib only).
