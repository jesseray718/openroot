# OpenRoot Contributor Lane Quiz (v1)

Answer each from 1 (low) to 5 (high):

1. I enjoy testing ideas with real-world measurements.
2. I like building physical systems/tools.
3. I enjoy growing food, soil care, seeds, and field practices.
4. I enjoy coding/automation/data workflows.
5. I can help with legal/policy/contracts/compliance.
6. I can help with finance/accounting/budget models.
7. I enjoy teaching, organizing events, and onboarding people.
8. I prefer clear tasks over open-ended exploration.
9. I want local, hands-on community impact.
10. I can commit at least 60 minutes per week.

## Scoring

- Highest in (1) → **Science Validation Lane**
- Highest in (2) → **Engineering/Build Lane**
- Highest in (3) → **Ag/Farm Lane**
- Highest in (4) → **Software/AI Lane**
- Highest in (5) → **Legal/Governance Lane**
- Highest in (6) → **Finance/Operations Lane**
- Highest in (7) → **Education/Community Lane**

If tied: pick the lane with the strongest motivation + easiest first task.

## If You Don’t Know What You Want Yet

Start with this 7-day empowerment path:
- Day 1: Read README + pick one micro-task
- Day 2: Reproduce one existing result
- Day 3: Share one improvement note
- Day 4: Pair with a contributor in your lane
- Day 5: Submit one PR or field report
- Day 6: Reflect: what gave you energy?
- Day 7: Commit to one monthly lane goal

## Foundational Actions Anyone Can Do Today

- Identify and document local heirloom seeds
- Map one local tool/resource library opportunity
- Start or support a community garden node
- Host a micro workshop (even 3 people)
- Log local problems needing practical solutions

## Contribution Ethos

- Mission over ego
- Credit shared fairly
- Responsibility goes to the best available steward
- Clear evidence beats loud claims
