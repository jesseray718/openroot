# OpenRoot Design Packets

A design packet is the durable public format for an OpenRoot idea, invention, experiment, BOM, blueprint, or reproducible system.

## Create a new packet

```bash
./scripts/new_design_packet.sh thermal-cascade "OpenRoot Thermal Cascade" "Jesse Ray McMillen"
```

A local note, superloop record, AI draft, or raw experiment is not automatically public knowledge. Promote it only after review for correctness, licensing, privacy, safety, and reproducibility.
