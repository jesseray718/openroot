# AX-029 — The Thin File Volatility Principle

**Domain:** Credit & Business (CB)
**Type:** Axiom
**Status:** Active

## Statement

A credit file with few accounts exhibits high score volatility per action. Each new tradeline or payment event has outsized impact. As the file thickens, individual actions carry less swing — the profile stabilizes. Early-stage actions therefore carry the highest marginal yield per effort.

## Derivation

Scoring algorithms normalize impact across number of accounts. With 1 account, a single event represents 100% of the data. With 10 accounts, a single event represents 10%. Therefore, marginal yield per action is inversely proportional to account count.

## Application

Front-load credit-building actions in the earliest stage. Every action taken when the file is thinnest produces maximum score movement. Delay is expensive — waiting to act means acting with less marginal impact.
