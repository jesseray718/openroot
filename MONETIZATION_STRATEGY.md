# OpenRoot Value Capture Model

**Absolute Commons — every tier below is free, for everyone, forever. No paid tiers, no subscriptions, no licensing fees.**

## 1. The Commons (FREE)
- Open Source Protocol
- Local Pod Tools
- Basic Receipt Generation

## 2. The Oracle (FREE)
- **Canonical Sealing:** "Root-Certified" seals on the main Newton Chain — open to every contributor at no cost.
- **Curated Intelligence:** "Master-Pods" of verified technical truth — published openly so every node can read, fork, and re-seal them.
- **Pathway Licensing:** "Optimal Logic Pathways" — released under the commons license so anyone can replay, refine, and re-seal them.

## 3. The Goal
Transition from manual labor to **Epistemic Compound**: value is proven at the point of **Verification** and returned to everyone at the point of **Creation**. OpenRoot is Absolute Commons — sustainability flows from the compounding commons itself, because each verified pathway makes the next one cheaper to prove.
