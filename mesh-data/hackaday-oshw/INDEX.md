# Hackaday / Open Source Hardware Seed
Focus: designs that can be built with common tools, scavenged or low-cost parts, and that increase local autonomy.

Priority categories:
1. Power (small solar, micro-hydro, bicycle generators, charge controllers)
2. Communications (LoRa, mesh radios, simple antennas, offline data)
3. Sensing & measurement (soil, water, air, energy monitoring)
4. Fabrication (CNC, 3D printing, casting, appropriate machine tools)
5. Repair & reverse-engineering documentation
6. Low-tech / high-robustness alternatives to brittle consumer devices

Starting points:
- Hackaday.io projects tagged "permaculture", "off-grid", "mesh", "appropriate technology"
- Hackaday.com "Art of Hardware" and long-running project logs with full BOMs
- Prefer projects with complete schematics, BOMs, and failure notes over pure demos

Mesh packaging rule: each project = one folder with README, BOM, files, and license.
