## Fractal Scaling Model (self-similar at every level)
- **Tier 0 (Nano)**: 1 specialized agent (Termux profiler, thermal modeler, context compressor, sensor oracle). On-device (Kai9000/Gemma, Ollama, llama.cpp on A15).
- **Tier 1 (Micro)**: 3-7 nanos + coordinator. Scoped sub-flows (RAM/battery optimization, git/SSH, one-liner generation).
- **Tier 2 (Meso)**: 8-49 agents. Cross-domain integrated flows (energy ledger + food production + compute scheduling + DeFi collateral).
- **Tier 3 (Macro)**: 50-500 agents. Governance + long-horizon strategy, quadratic ACRE voting, recursive self-improvement of the swarm.
- **Tier 4 (Macro-Mesh / Grove-Forest)**: 500+ agents across multiple physical nodes. Inter-site coordination, global PoPW verification mesh, ACRE multiplier pools, thermal cascade orchestration across domes/aquaponics clusters. Self-similar governance with quadratic voting weighted by verified physical yield.

Every tier uses identical UNE nomenclature, Kingdom Engine roles (Steward, Engineer, Oracle, Governor, Verifier), feedback loops, and PoPW verification primitives.
